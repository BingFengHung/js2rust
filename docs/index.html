01 / CODE IN TRANSLATION

你寫的，
就是起點。

切換範例，看看同一個想法如何變成 Rust。
以下程式碼由專案轉譯器產生。

JS JavaScript main.js 
function main() {
  const numbers = [1, 2, 3];
  const doubled = numbers.map(value => value * 2);
  const total = doubled.reduce((sum, value) => sum + value, 0);
  console.log(doubled);
  console.log(total);
}
RS Rust main.rs 
fn main() {
    let numbers: Vec<i64> = vec![1, 2, 3];
    let doubled: Vec<i64> = numbers.iter().cloned()
        .map(|value| { value * 2 }).collect();
    let total = doubled.iter().cloned()
        .fold(0, |sum, value| { sum + value });
    println!("{:?}", doubled);
    println!("{}", total);
}

map 產生新陣列；reduce 累加結果，原陣列仍可使用。

CURRENT SCOPE

從明確的子集，
一步步擴展。

這個工具目前無法直接執行完整 Node.js 應用程式。

  • 陣列使用相同型別的元素。
  • 方法回呼使用內嵌函式；不支援修改來源陣列。
  • split 不支援正規表示式；空分隔符遇非 BMP 字元會明確失敗。
  • 動態型別、完整數值／UTF-16 語意仍有限制。
  • Node.js、npm 套件及 HTTP Server API 尚未對接。

03 / YOUR FIRST TRANSLATION

從第一段
程式碼開始。

需要 Node.js 與 npm。
編譯及執行 Rust 另外需要 Rust 工具鏈。

STEP 01

取得並安裝

下載專案，在終端機進入專案目錄。

git clone https://github.com/BingFengHung/js2rust.git
cd js2rust
npm ci

若儲存庫為私人，請先登入具有權限的 GitHub 帳號。

STEP 02

打開本機 Playground

在瀏覽器編輯 JS，即時查看 Rust 並匯出專案。

npm run playground

# 開啟 http://localhost:3000

在線執行會將 Rust 程式碼送至官方 Rust Playground。

偏好命令列？查看 CLI 與測試指令 ＋

匯出 Rust

npm start -- test/example.js -o output.rs
rustc --edition=2021 output.rs

執行產出的二進位程式；使用 Tokio 的專案請以 Cargo 編譯。

驗證專案

npm test
npm run test:rust

test:rust 需要 rustc 與 cargo；缺少工具會明確失敗。
